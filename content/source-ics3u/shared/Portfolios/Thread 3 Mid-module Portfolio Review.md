Portfolio reviews will occur in class this Thursday, January 23, or through Grove Time if you will not be present that day.

## How to prepare

Quite simply, be sure you have completed both the lesson and exercises for each day of this module, and shared that progress clearly in your portfolio, with an individual portfolio post for each day.

Be ready to have a brief conversation about any, though probably not all of these topics, based on available time:

- using bindings to connect input controls to a stored property
- use of lists (arrays), including dynamic lists
- use of selection (`if`) statements
- concepts involved in handling user input, in particular:
	- optional data types
	- use of `guard` statements when converting from one data type to another
- identifying what parts of your program:
	- take input
	- process input
	- show output

You should be able to confidently speak about how any of these concepts are used in programs you have authored in this module. You've got this. 🚀
