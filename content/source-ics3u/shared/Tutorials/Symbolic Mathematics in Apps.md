Mathematics has been described as the universal language – so it is only natural that we would seek to find ways to use [symbolic mathematics](https://www.madscitech.org/guide/Introduction%20to%20Symbolic%20Mathematics.pdf) in applications we write to help others.

[$\\LaTeX$](https://www.latex-project.org/get/) (pronounced "lay-tech") is a "document preparation system" that sits atop [Donald E. Knuth's $\\TeX$ typesetting sytem](https://en.wikipedia.org/wiki/Donald_Knuth). In academia, $\\LaTeX$ syntax is widely used for expressing symbolic mathematics on a computer. If you proceed into post-secondary studies in science, technology, engineering, or mathematics, it is virtually certain that you will see, and perhaps write, $\\LaTeX$ to express mathematical concepts at some point during your studies.

It is beyond the scope of this tutorial to explain $\\LaTeX$ syntax, but the [following reference sheet](https://quickref.me/latex) is useful.

The purpose of this tutorial is to explain how to use [$\\LaTeX$SwiftUI](https://github.com/colinc86/LaTeXSwiftUI) package, which makes it possible to use $\\LaTeX$ within an app that uses the SwiftUI framework to show a user interface.

> [!NOTE]
> 
> There are other third-party packages that make it possible to use $\\LaTeX$ in a SwiftUI app, but [$\\LaTeX$SwiftUI](https://github.com/colinc86/LaTeXSwiftUI) is the one that Mr. Gordon has generally found the easiest to use.
